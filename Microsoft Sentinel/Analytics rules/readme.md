
# Analytics rules

Collection of **analytics rules** for Microsoft Sentinel.

## 🔍 What is Analytics rule?

An analytics rule monitors data in Sentinel and looks for specific patterns, anomalies, or indicators of malicious activity based on defined criteria. When those conditions are met, the rule can generate an alert, create an incident, and trigger automated response actions.

## 🎯 Analytics rules list

- [App Service AV detections](./App%20Service%20AV%20detections/) - Scheduled analytics rule to **detect new infected files in App Services** from the antivirus scan audit log.
- [App Service AV failures](./App%20Service%20AV%20failures/) - Scheduled analytics rule to **detect AV scan errors in App Services** from the antivirus scan audit log.
