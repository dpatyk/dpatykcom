# Microsoft Sentinel

Collection of **templates** for various Microsoft Sentinel components.

## 🔍 What is Microsoft Sentinel?

Microsoft Sentinel is a cloud-native SIEM and SOAR platform from Microsoft that helps organizations collect, analyze, and correlate security data across on-premises, cloud, and hybrid environments. It supports threat detection, incident investigation, and automated response, enabling security teams to enhance visibility and respond more quickly to attacks.

## 🎯 Supported content

- [Analytics rules](./Analytics%20rules/) - Sentinel alerts that point to relevant SOC actions through incidents.
