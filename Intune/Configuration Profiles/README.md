# Intune Remediations

Collection of **configuration profiles** for Microsoft Intune.

## 🔍 What is Configuration Profile?

Device configuration profiles allow you to add and configure device settings, and then push these settings to devices in your organization.

Each configuration profile is a **previously exported settings catalog policy** that you can import in Microsoft Intune.

## 🎯 Configuration Profiles list

- [Windows - Google Chrome - Extensions](./Windows%20-%20Google%20Chrome%20-%20Extensions/) - Intune **configuration profile** that control Google Chrome extensions **Allow**, **Block** and **Forcelist**.
- [Windows - Microsoft Edge - Extensions](./Windows%20-%20Microsoft%20Edge%20-%20Extensions/) - Intune **configuration profile** that control Microsoft Edge extensions **Allow**, **Block** and **Forcelist**.
