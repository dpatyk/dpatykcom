# Intune Remediations

Collection of **remediations scripts** for Microsoft Intune.

## 🔍 What is Remediation?

Remediations are script packages that can detect and fix common support issues on a user's device before they even realize there's a problem.

Each package consists of a **detection** and a **remediation** scripts. When you use Intune, you can deploy these script packages and see reports on their effectiveness.

## 🎯 Remediation list

- [Wazuh-Agent-Scripts](./Wazuh-Agent-Scripts/) - Intune **run remediation** scripts for **one-time** installation, uninstallation or upgrade Wazuh agent on a specific device.
